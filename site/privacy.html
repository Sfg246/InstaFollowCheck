Privacy

FollowCheck never asks visitors for their Instagram password.

When you scan a public username, that username is sent to the FollowCheck backend. The backend uses the site owner's dedicated Instagram collector session to request the public profile, followers, and following data required for the comparison.

The collector account credentials and saved session stay on the private backend server. They are never shipped to the website or browser.

The comparison and selection interface run in your browser. FollowCheck stores lightweight preferences on your device, including the optional site access code and usernames you mark as handled.

The default backend uses short-lived in-memory caching to reduce repeated Instagram requests and does not include a follower database. Normal server/reverse-proxy logs may still contain request metadata such as IP address and timestamps.

Private Instagram targets are intentionally refused. FollowCheck is not affiliated with Instagram or Meta.
