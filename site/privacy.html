Privacy

FollowCheck does not ask for or store your Instagram password.

When you run a username-only scan, the Instagram username you enter is sent to the FollowCheck backend. The backend sends that username to the configured public-data provider to request the public profile, followers, and following lists needed for the comparison.

The comparison and selection interface run in your browser. FollowCheck stores only lightweight preferences on your device, such as the optional site access code and the usernames you mark as handled. These values use browser local storage.

The default backend is designed not to write follower/following results to a database and returns responses with Cache-Control: no-store. Your hosting provider and API provider may still process normal request metadata such as IP address and timestamps under their own policies.

FollowCheck is not affiliated with Instagram or Meta. Only use the service in ways permitted by applicable platform rules and law.
